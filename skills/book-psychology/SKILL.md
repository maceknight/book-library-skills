# 心理・行動経済学

使うときは、相談の共通ルール・根拠レベル・共通原則のために **book-core** も読む（まだ読んでいなければ）。

このSkillは単独の相談にも使うが、ほかの分野の相談で「なぜそうしてしまうのか」を説明するレンズとして使われることが多い。
バイアスの詳細な説明はこのSkillだけが持つ。ほかのSkillはここを参照し、同じ説明をコピーしない。

## このSkillの定義

| 項目 | 内容 |
|---|---|
| どんな相談で使うか | 自分や他人の不合理な判断の理由、行動を変えるための仕掛け、マーケティング・販売での心理の使い方 |
| 発動する状況 | 「分かっているのにできない」「つい〜してしまう」。人に行動してもらいたい（顧客、部下、家族）。価格・選択肢・見せ方の設計 |
| 何を判断するか | どのバイアスが働いているか、それを打ち消すか利用するか、どんな仕掛けなら行動が変わるか、その仕掛けが相手のためになっているか |
| 提案する行動 | バイアスへの対策（事前に決める、デフォルトを変える、比較の枠を変える）、ナッジの設計、選択肢と情報の見せ方の改善 |
| 他Skillとの連携 | お金の判断のクセ → 主担当 book-money。先延ばし・習慣 → 主担当 book-time-habit。組織での動機づけ → 主担当 book-work。意思決定の手順 → book-core 共通原則「意思決定」 |

## モジュール

| モジュール | 扱う相談 | 本 |
|---|---|---|
| `modules/biases.md` 判断のクセ | 自分や他人の判断がずれる理由、バイアスの一覧と対策 | #38 |
| `modules/nudge.md` 行動を変える仕掛け | ナッジ、選択肢の設計、価格や見せ方、マーケティングへの応用 | #38 |

蔵書一覧と取り込み状況は `references/index.md`。

## 答え方

1. `references/index.md` で、状態が「作成済」か「事前」の本を確認する。
2. 該当モジュールを読む。
3. 働いているバイアスの名前 → なぜそうなるか → 対策・仕掛け → 根拠（書名と根拠レベル）の順で答える。
4. 行動経済学の個々の研究には、再現性が議論になっているものがある。ノートに注意があれば添える。

## この分野の注意

- **相手をだます使い方は勧めない。** 人の弱みにつけ込んで本人の利益に反する行動をさせる設計（ダークパターン）ではなく、本人や顧客のためになる方向の仕掛けを提案する。売り方の相談では、長期的な信頼を損なわないかも一言添える。
