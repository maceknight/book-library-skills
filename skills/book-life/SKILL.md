# 生活・メンタル

使うときは、相談の共通ルール・根拠レベル・共通原則のために **book-core** も読む（まだ読んでいなければ）。

## このSkillの定義

| 項目 | 内容 |
|---|---|
| どんな相談で使うか | 暮らしを回すこと（生活の事務）と、心の持ち方・生き方 |
| 発動する状況 | 生活の事務が回らない、忘れ物・遅れ・散らかり。特性による困りごと。自己嫌悪、落ち込み、不安。言葉や考え方を変えたい。生きる意味や人との関係 |
| 何を判断するか | 困りごとが仕組みで解決できるものか、気持ちの持ち方の問題か、専門家の支援が必要な状態か |
| 提案する行動 | 生活の事務の仕組み化、特性に合わせた環境の工夫、言葉や考え方の小さな習慣、感謝や他者への貢献の視点 |
| 他Skillとの連携 | 仕組み化／行動の初速／有限性 → book-core 共通原則。習慣づくり → book-time-habit。お金の不安 → book-money。仕組み化の考え方（組織の仕組み化） → book-work |

## モジュール

| モジュール | 扱う相談 | 本 |
|---|---|---|
| `modules/life-admin.md` 生活の事務・困りごと | 手続き・お金・予定の管理、片づけ、特性がある人の生活の工夫、落ち込んだときの立て直し方 | #11、#13 |
| `modules/mind.md` 心の持ち方・言葉・生き方 | 口癖、前向きな考え方、願いと現実の関係、誰のために生きるか | #39、#40、#42 |

蔵書一覧と取り込み状況は `references/index.md`。

## 答え方

1. `references/index.md` で、相談に関係し、状態が「作成済」か「事前」の本を確認する。
2. 該当モジュールの「統合した判断ルール」と「論点」を読む。根拠を示すときは本のノートも読む。
3. 結論 → 根拠（書名と根拠レベル）→ 当てはまらない条件、の順で、相談者の気持ちに配慮した口調で答える。

## この分野の注意

- **安全を最優先する。** 死にたい気持ち、長く続く強い落ち込み、眠れない・食べられない状態、日常生活が回らないほどの困難があるときは、本の知識で答えるより先に、医療機関や相談窓口につなぐ。本の助言は受診の代わりにしない。
- **診断をしない。** 「発達障害かもしれない」という相談には、本の工夫を紹介しつつ、診断は専門家が行うものだと伝える。
- **スピリチュアル系の主張は根拠レベルを明示する。** 引き寄せの法則などは、「考え方として役に立つ面」と「事実として検証されていない主張」を分けて伝える。お金や健康の重要な判断を、こうした主張だけに基づいて勧めない。
