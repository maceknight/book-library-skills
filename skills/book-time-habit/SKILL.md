# 時間・習慣・行動

使うときは、相談の共通ルール・根拠レベル・共通原則のために **book-core** も読む（まだ読んでいなければ）。

## このSkillの定義

| 項目 | 内容 |
|---|---|
| どんな相談で使うか | 限られた時間を何に使うか、どう動き出し、どう続けるか |
| 発動する状況 | 忙しい・時間がない・優先順位が決められない。休日や一日の過ごし方。先延ばし、やる気、三日坊主、習慣づくり |
| 何を判断するか | 本当に重要なことは何か、何をやめるか、どの時間帯に何をするか、行動が止まっている原因（ハードルの高さ・仕組みの不足・そもそも不要） |
| 提案する行動 | やらないことリスト、時間の使い方の見直し、一日・一週間の設計、最初の一歩を小さくする、続ける仕組み |
| 他Skillとの連携 | 選ぶ・減らす／行動の初速／有限性 → book-core 共通原則。仕事の中身の効率化 → book-work。続かなくて自己嫌悪が強い → book-life。先延ばしの心理的な理由 → book-psychology |

## モジュール

| モジュール | 扱う相談 | 本 |
|---|---|---|
| `modules/priority.md` 優先順位・やらないこと | やることが多すぎる、何が重要か分からない、忙しさの感覚 | #14、#17、#26、#28 |
| `modules/time-design.md` 時間の設計 | 一日・休日の組み立て、時間帯ごとの向き不向き、充実感 | #15、#16、#17、#30 |
| `modules/action-habit.md` 動き出す・続ける | すぐ動けない、先延ばし、習慣が続かない、行動する勇気 | #24、#35、#36 |

蔵書一覧と取り込み状況は `references/index.md`。

## 答え方

1. `references/index.md` で、相談に関係し「作成済」の本を確認する。
2. 該当モジュールの「統合した判断ルール」と「論点」を読む。根拠を示すときは本のノートも読む。
3. 「時間がない」の中身（本当に量が多いのか、重要でないことに使っているのか、忙しいと感じているだけか）で答えが変わるので、分からなければ先に聞く。
4. 結論 → 根拠（書名と根拠レベル）→ 本によって違う点 → 当てはまらない条件、の順で答える。

## この分野の注意

- **提案は1〜3個に絞る。** 時間の悩みを抱えた人に、やることを10個渡すと逆効果になる。
- **疲れや不調が続いている場合は、時間術より休養や受診を優先する。** 睡眠が取れない、気分の落ち込みが続くなどのときは book-life と連携する。
