# 仕事術・マネジメント

使うときは、相談の共通ルール・根拠レベル・共通原則のために **book-core** も読む（まだ読んでいなければ）。

## このSkillの定義

| 項目 | 内容 |
|---|---|
| どんな相談で使うか | 仕事の考え方、人と組織の動かし方、伝え方、仕事の基本とキャリア・学び方 |
| 発動する状況 | 問題が整理できない、決められない、報告や説明がうまくいかない、部下・外注先・チームの管理、評価や目標設定、スキルアップや独学 |
| 何を判断するか | 本当の問題（本質）は何か、何を数字で追うか、誰が何の責任を持つか、どう伝えれば伝わるか、どこで戦うか |
| 提案する行動 | 問題の分解と仮説、数値目標と行動量の設定、ルールと役割の明文化、言語化の手順、報告の型、学習計画 |
| 他Skillとの連携 | 仕組み化／意思決定／数値化 → book-core 共通原則。人の判断のクセや動機づけ → book-psychology。仕事が多すぎて時間が足りない → book-time-habit。事業の利益 → book-money |

## モジュール

| モジュール | 扱う相談 | 本 |
|---|---|---|
| `modules/thinking.md` 考え方・問題解決 | 本質をつかむ、問題の分解、数値で考える、効率よく成果を出す | #18、#22、#23、#27 |
| `modules/management.md` マネジメント・組織 | 部下・チームの管理、仕組み化、評価、リーダーの振る舞い、組織での意思決定 | #19、#20、#21、#22 |
| `modules/communication.md` 言語化・伝え方 | 考えを言葉にする、説明・報告・会議、伝わる話し方 | #23、#25、#31 |
| `modules/career-basics.md` 仕事の基本・キャリア・学び方 | 仕事ができる人の基本動作、信頼の積み方、弱い立場での戦略、独学 | #25、#32、#33、#34 |

#19〜#22 は同じ著者（識学）の一連の本で、1つの体系として統合して扱う。ほかの本と考え方が違う点（例：リーダーが感情をどこまで出すか）は「論点」に書く。

蔵書一覧と取り込み状況は `references/index.md`。

## 答え方

1. `references/index.md` で、相談に関係し「作成済」の本を確認する。
2. 該当モジュールの「統合した判断ルール」と「論点」を読む。根拠を示すときは本のノートも読む。
3. 相談者の立場（一人で働く／リーダー／メンバー、会社員／経営者）で答えが変わるなら、先に聞く。
4. 結論 → 根拠（書名と根拠レベル）→ 本によって違う点 → 当てはまらない条件、の順で答える。

## この分野の注意

- **組織論は前提となる組織の形で効き方が変わる。** 大きな組織向けの助言を一人会社や小さなチームにそのまま当てはめない。company-os と一緒に使うときは特に。
