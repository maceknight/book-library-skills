# 数値化の鬼

> **事前ノート**：Claudeの事前知識から作成。ユーザーのハイライトで未確認。章の順番と細部は要確認。

## 一言で

仕事の不足や成果を感覚ではなく数字で捉え、まず行動量を数え、確率や率に逃げず、結果を本当に左右する変数に集中し、長い期間で考えることで、誰でも「仕事ができる人」になれる。

## 著者の立場

- 識学の創業者。『リーダーの仮面』の続編にあたり、個人とマネジャーの両方に向けた本
- 利益相反：識学の研修・コンサルティングを販売

## 判断ルール

1. **まず行動の「量」を数える** — 何回やったかを数字にしない限り、改善できない。［根拠: B］
2. **自分の不足を数字で認める** — 「頑張った」ではなく、目標との差を数字で見る。言い訳を減らす。［根拠: B］
3. **確率（率）に逃げない** — 成約率などの割り算の数字だけを見ると、分母（行動量）を増やす努力を怠る。まず分母を増やす。［根拠: C］
4. **結果に影響する変数を見極める** — 数字にできる要素のうち、何を変えれば結果が変わるのかを絞る。［根拠: B］
5. **「真の変数」以外は捨てる** — 影響の小さい変数に時間を使わない。［根拠: B］
6. **短期の数字だけでなく、長い期間で考える** — 目先の数字を追って将来の成果を損なわない。［根拠: B］
7. **数字は人を責める道具ではなく、改善のための共通言語** — 評価の基準を数字で置くと、上司と部下の認識のずれが減る。（要確認：表現）［根拠: C］

## 具体的な手法・数字

- 流れ：行動量 → 確率 → 変数 → 真の変数 → 長い期間（要確認：章立て）
- 「PDCA」を数字で回す
