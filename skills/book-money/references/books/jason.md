# ジェイソン流お金の増やし方

> **事前ノート**：Claudeの事前知識から作成。ユーザーのハイライトで未確認。改訂版（新NISA対応）の細部、「10の方法」の中身は特に要確認。

## 一言で

まず支出を徹底的に減らして投資に回すお金を作り、低コストのインデックスファンドに長期・分散・積立で投資し、相場が荒れても売らずに続ける。

## 著者の立場

- 芸人であり、IT企業の役員も務めた人物。米国出身で、米国式の資産形成を日本の読者向けに伝える
- 対象は投資未経験の会社員・若い世代
- 利益相反：特定の金融商品やサロンを売る本ではない（要確認）

## 判断ルール

1. **お金を増やす第一歩は、支出を減らすこと** — 収入を増やすより確実で、すぐできる。［根拠: B］
2. **買う前に「本当に必要か」を問う。見栄の出費をしない** — 周りに合わせた消費、ブランド品、使わないサブスクを削る。［根拠: B］
3. **固定費から見直す** — 通信費・保険・住居費など、一度下げれば効果が続くものを優先する。（要確認：本での具体例）［根拠: B］
4. **投資は低コストのインデックスファンドで、長期・分散・積立** — 個別株の銘柄選びや短期売買で市場平均に勝ち続けるのは難しい。米国株全体やS&P500のような広く分散した指数が中心。［根拠: A］
5. **暴落しても売らない。積立を止めない** — 下がったときは安く買えている。慌てて売るのが最大の失敗。［根拠: A］
6. **税制優遇の口座（NISA）を優先して使う**。［根拠: A（制度の詳細は時期で変わる）］
7. **早く始める** — 時間を味方につける（複利）ことが最大の武器。［根拠: A］

## 根拠の評価

- 低コスト・分散・長期のインデックス投資の優位は、長期データと多くの研究で支持されている（補足）
- 米国株中心の配分は、過去の米国市場の好成績に依存する面がある。将来も同じとは限らない（補足）
