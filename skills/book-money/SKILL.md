# お金・投資

使うときは、相談の共通ルール・根拠レベル・共通原則のために **book-core** も読む（まだ読んでいなければ）。

## このSkillの定義

| 項目 | 内容 |
|---|---|
| どんな相談で使うか | 貯める・使う・増やす・守るに関わる相談全般。個人の資産形成と、事業の利益の両方 |
| 発動する状況 | 金額・収入・支出・資産・投資商品・制度（NISA等）が話題に出たとき。お金の不安や価値観の話。事業の売上・利益・価格の話 |
| 何を判断するか | 今の家計で優先すべきこと、投資するか・何にどれだけか、そのリスクが相談者に合うか、目標金額の妥当さ、事業で追うべき数字 |
| 提案する行動 | 家計の見える化、先取り・自動化、投資方針（配分・積立額・続け方）の決め方、暴落時のルールを事前に決める、利益を基準にした事業判断 |
| 他Skillとの連携 | 貯められない・衝動買い・損切りできない → book-psychology。投資の決め方 → book-core 共通原則「意思決定」。事業の何をやめるか → book-work。お金の不安が強く生活に響いている → book-life |

## モジュール

相談に合うモジュールを読む。複数にまたがる相談なら両方読む。

| モジュール | 扱う相談 | 本 |
|---|---|---|
| `modules/household.md` 家計・貯める・使う | 貯金、節約、支出の見直し、金利・税金・保険の基礎、FIREの計画 | #3、#4、#5、#7、#8、#10、#41 |
| `modules/investing.md` 投資判断 | 何に投資するか、配分、銘柄の選び方、暴落時、情報との付き合い方 | #1、#2、#6、#8、#9、#10、#12 |
| `modules/money-mind.md` お金との向き合い方 | 足りない不安、いくらあれば幸せか、富裕層の考え方、お金の使い道の価値観 | #2、#3、#7、#29、#41 |
| `modules/business-profit.md` 事業の利益 | 売上と利益、利益率、何を売らないか、価格設定 | #37 |

蔵書一覧と取り込み状況は `references/index.md`。

## 答え方

1. `references/index.md` で、相談に関係し「作成済」の本を確認する。
2. 該当モジュールの「統合した判断ルール」と「論点」を読む。根拠を示すときは本のノート（`references/books/`）も読む。
3. 相談者の状況（年齢、収入、資産、家族、目的、リスクの許容度）で答えが変わるなら、先に1〜2点聞く。
4. 結論 → 根拠（書名と根拠レベル）→ 本によって違う点 → 当てはまらない条件、の順で答える。

## この分野の注意

- **制度・数字は古くなる。** NISA・税制・金利・利回りはノートの読了日時点の情報として扱い、最新の確認を促す。
- **個別銘柄・個別商品の売買は勧めない。** 本に出てくる銘柄は「本ではこう紹介されている」として、判断材料の説明にとどめる。
- **利益相反に触れる。** 著者がセミナー・サロン・特定の商品で収益を得ている場合（ノートの「著者の立場」に記録）、関係する助言では一言添える。
- **個人のお金と事業のお金を区別する。** company-os の財務として答えるときは特に。
